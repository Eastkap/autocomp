# tool: GTM knowledge base — curated sources

Owner-curated references the marketer/sales roles should consult when planning GTM for any
venture. Pull tactics from these BEFORE inventing strategy; cite which source a tactic came
from in the plan.

## First-1000-users tactics
- **https://1kusers.com/feed** — feed of how real products got their first 1,000 users;
  mine it for tactics matching the venture's ICP + channel constraints.
- **https://www.first1k.me/** — first-1000-users case-study library; same use.

## Launch directories (see `tools/directories.md` for the full playbook)
- https://startupsubmit.app/best-startup-directories
- https://ideaproof.io/tools/category/launch-directories
- https://launchdirectories.com

## How roles use this
1. When a GTM plan is needed, the marketer skims the relevant source(s) via `tools/web.md`
   (fetch → extract tactics that fit the charter's allowed channels + budget).
2. Shortlist 2–3 tactics with a verifiable success criterion each; the Hundred-Dollar Test
   decides which one runs first.
3. Anything involving spend or outbound sends stays gated as usual.
4. Tactics that worked/failed for a venture get written to its `private/memory/` so the
   knowledge compounds (CLAUDE.md principle 8).
